# Biscuits du Dev : des starterkits propres pour les vibe coder 🍪

À la base, **Biscuits du Dev** c'est parti d'un truc simple : je voyais plein de *vibe coder* qui veulent lancer des projets, vendre des sites, des SaaS… mais avec des bases techniques bancales, du code copié-collé, zéro perf, zéro SEO.

Plutôt que juste **râler sur Twitter / TikTok**, j'ai décidé de transformer ça en **business**.

<Callout type="tip">
Ce projet est né d'une frustration : voir des devs talentueux galérer à cause d'une base technique fragile. Au lieu de critiquer, j'ai créé la solution.
</Callout>

---

## 🎯 L'idée derrière Biscuits du Dev

L'objectif n'est pas de juger, mais de partir d'un **constat simple** :

**Le problème** :
- Tout le monde n'a pas le temps de lire toute la doc Next.js / Astro / Supabase
- Beaucoup veulent **ship vite**, mais sans vraiment comprendre la stack
- Résultat ? Des sites lents, une architecture freestyle, du SEO inexistant et une maintenance impossible

**La solution** :
Du coup, j'ai créé **Biscuits du Dev** : des **starterkits bien pensés**, clé en main, que les vibe coder peuvent utiliser pour **partir sur de bonnes bases**.

<Callout type="info" title="Pour qui ?">
Ces starterkits s'adressent aux **développeurs qui veulent shipper rapidement** sans sacrifier la qualité. Que tu sois freelance, entrepreneur ou en train de lancer ton side project, tu trouveras ton bonheur.
</Callout>

## 💼 Ce que je vends concrètement

Aujourd'hui, Biscuits du Dev tourne autour de **trois packs principaux** :

### 🚀 StarterKit Next.js Pro — ~500 €

Pour les projets type **site vitrine / portfolio / petit SaaS**

**Ce qui est inclus :**
- App Router avec React Server Components
- TypeScript en mode strict
- Auth prête à brancher (NextAuth.js)
- SEO optimisé : Open Graph, JSON-LD, sitemap
- Structure professionnelle pour scaler facilement

<Callout type="success">
Idéal pour lancer ton portfolio, ton site vitrine ou ton premier SaaS sans passer 3 semaines sur la config !
</Callout>

### ⚡ StarterKit Astro Local Business — ~400 €

Pour les **sites vitrines ultra rapides** (commerces, artisans, indépendants)

**Ce qui est inclus :**
- 100% Static Site Generation
- Score Lighthouse 100/100 possible
- Schema LocalBusiness + Service en JSON-LD
- Pages pré-conçues : Services, Contact, Tarifs, Devis

### 💎 StarterKit SaaS complet avec Supabase — ~800 €

Pour ceux qui veulent un **vrai SaaS** sans se prendre la tête

**Ce qui est inclus :**
- Auth complète (email / magic link / OAuth)
- Système de rôles + Row Level Security
- Dashboard + billing prêt à étendre (Stripe)
- Architecture propre : services, hooks, components
- Documentation complète

<Callout type="warning">
Ce pack nécessite des connaissances de base en React et TypeScript. Si tu débutes complètement, commence par le pack Next.js Pro !
</Callout>

## 🎁 Principe des starterkits

**Chacun de ces kits est pensé pour que tu puisses :**

1. **Cloner → configurer → personnaliser** en quelques heures
2. Te concentrer sur **le contenu, le design et la vente**
3. Utiliser une base technique **solide qui ne s'effondre pas au premier client**
