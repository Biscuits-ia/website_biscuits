# Comment détecter une arnaque avec l'IA ?

Les arnaques en ligne se multiplient et deviennent de plus en plus sophistiquées. L'IA peut vous aider à les repérer avant qu'il ne soit trop tard.

<Callout type="warning">
En France, les escroqueries en ligne représentent plusieurs milliards d'euros de pertes annuelles pour les particuliers et les associations.
</Callout>

---

## 🚩 Les signaux d'alerte classiques

Voici les indices qui doivent vous alerter :

- **Urgence artificielle** : "Vous avez 24h pour répondre !"
- **Fautes d'orthographe ou syntaxe approximative** dans l'email ou le message
- **Lien suspect** : l'URL ne correspond pas à l'organisation censée vous contacter
- **Demande d'informations sensibles** : mot de passe, IBAN, code de sécurité
- **Expéditeur inconnu** avec un nom de domaine étrange (ex : `banque-france.support-urgent.ru`)

---

## 🤖 Comment l'IA peut vous aider

Plusieurs outils d'IA sont disponibles gratuitement pour analyser les messages suspects :

### 1. Analyse de texte par IA générative
Copiez le contenu de l'email suspect dans un outil comme ChatGPT ou Claude et demandez : *"Est-ce que ce message ressemble à une tentative de phishing ?"*

### 2. Vérification des liens
Des services comme [VirusTotal](https://www.virustotal.com) ou [URLScan.io](https://urlscan.io) analysent les liens automatiquement.

### 3. Outils de notre association
Biscuits IA développe un simulateur de détection d'arnaque accessible depuis notre espace d'outils. Il analyse le texte, l'expéditeur et les liens en temps réel.

---

## ✅ Checklist anti-arnaque

Avant de cliquer ou de répondre à un message :

- [ ] J'ai vérifié l'adresse email de l'expéditeur (domaine complet)
- [ ] Je n'ai pas cliqué sur les liens sans les avoir vérifiés
- [ ] Je n'ai pas fourni de données personnelles ou bancaires
- [ ] J'ai signalé le message suspect à [Pharos](https://www.internet-signalement.gouv.fr)

<Callout type="success">
En cas de doute, appelez directement l'organisation concernée via leur numéro officiel.
</Callout>
