L'idee que "faire tourner une IA" necessite des serveurs a 50 000 EUR et une equipe d'ingenieurs, c'est fini. Aujourd'hui, un simple PC portable peut executer un modele de langage performant. Et la facon la plus simple d'y arriver, c'est Ollama.

Ollama est un outil open source qui installe, configure et fait tourner des modeles IA en une seule commande. Pas de configuration complexe, pas de Python a installer, pas de GPU obligatoire. Juste une commande et ca marche.

<Callout type="info" title="Pour qui ce guide est-il ecrit ?">
Pour les personnes qui n'ont jamais touche a un terminal. Ollama a l'air d'un outil de geek, mais en pratique, vous allez taper 3-4 commandes et tout fonctionnera.
</Callout>

---

## Pourquoi Ollama plutot qu'un autre outil ?

Il existe plusieurs solutions pour faire tourner un LLM localement (LM Studio, GPT4All, Jan). Ollama se distingue par sa **simplicite radicale** et sa **philosophie Unix** : un outil qui fait une chose et qui la fait bien.

### Les avantages concrets pour une structure

- **Installation en une ligne** : `curl -fsSL https://ollama.com/install.sh | sh`
- **Telechargement de modele en une ligne** : `ollama pull phi4`
- **Lancement en une ligne** : `ollama run phi4`
- **API REST automatique** : votre LLM expose une API locale sur `http://localhost:11434`
- **Confidentialite totale** : rien ne quitte votre machine
- **Gratuit** : pas d'abonnement, pas de quota

## Installation pas a pas

### Sur macOS

Si vous avez un Mac (Apple Silicon ou Intel), telechargez l'installateur depuis https://ollama.com/download, double-cliquez, c'est fait.

### Sur Linux

Une seule commande dans votre terminal :

```
curl -fsSL https://ollama.com/install.sh | sh
```

### Sur Windows

Installez Ollama via le sous-systeme Linux (WSL2) ou telechargez l'installateur Windows.

### Verification

Une fois installe, ouvrez un terminal et tapez :

```
ollama --version
```

---

## Telecharger votre premier modele

Ollama propose un catalogue de modeles sur https://ollama.com/library. Pour un premier test, on va installer **Phi-4** de Microsoft : 14 milliards de parametres, qualite honorable, tourne sur un PC avec 16 Go de RAM.

```
ollama pull phi4
```

Pour un PC modeste, vous pouvez essayer **Gemma 3 4B** (4 milliards de parametres, ~2 Go) :

```
ollama pull gemma3:4b
```

---

## Lancer une conversation

Une fois le modele telecharge, lancez-le :

```
ollama run phi4
```

Vous entrez dans un chat interactif. Posez votre premiere question :

```
>>> Bonjour, peux-tu te presenter en 3 phrases ?
```

Phi-4 repond en francais, explique qu'il est un modele d'IA de Microsoft, et precise ses limites. Tapez `/bye` pour quitter la conversation.
